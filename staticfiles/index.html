Professional Selling System Built with Django

A comprehensive e-commerce platform with product catalog, shopping cart,
order management, and user authentication.

Django Bootstrap 5 HTML5 CSS3 JavaScript

Key Features

Product Catalog

Browse products by categories with advanced search and filter options.

Shopping Cart

Add, remove, and update items with real-time cart summary.

Secure Checkout

Multiple payment options with order tracking and confirmation.

User Accounts

Register, login, manage profile, and view order history.

Wishlist

Save favorite products for later purchase.

Admin Dashboard

Sales analytics, order management, and product control.

Installation Instructions

1. Install Dependencies
pip install django pillow whitenoise
2. Run Migrations
python manage.py migrate
3. Create Sample Data
python manage.py create_sample_data
4. Run the Server
python manage.py runserver
5. Access the Application
Website: http://127.0.0.1:8000/
Admin: http://127.0.0.1:8000/admin/

Admin Login: admin / admin123
Customer Login: customer / customer123
